Questions fréquentes

Faut-il créer un compte ?
Non. Finao fonctionne sans compte et sans connexion : tes données restent sur ton téléphone.

Comment ne pas perdre mes données en changeant de téléphone ?
Dans Paramètres, Sauvegarde et données : crée une sauvegarde protégée par un mot de passe, range le fichier en lieu sûr, puis restaure-la sur le nouveau téléphone (iPhone ou Android). Sans ce mot de passe, la sauvegarde ne peut pas être ouverte.

J'ai oublié mon code de verrouillage.
Si tu as activé Face ID ou l'empreinte, utilise-les. Sinon, le code ne peut pas être récupéré : il faut supprimer puis réinstaller Finao, et restaurer ta dernière sauvegarde si tu en as une.

Pourquoi le Copilote n'est-il pas disponible ?
Le Copilote fait tourner un modèle d'IA directement sur le téléphone. Il faut un téléphone assez puissant (au moins 6 Go de mémoire) et télécharger une fois le modèle (environ 2,5 Go, de préférence en Wi-Fi). Sans lui, toutes les autres fonctions de Finao restent disponibles.
